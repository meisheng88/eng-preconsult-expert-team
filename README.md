# 工程前期咨询专家团

说出你的工程项目，9位专家从策划、调研、可研、评估到报批全程协作，助你快速完成前期咨询与立项决策。

## 类型

Team 型（多角色协作团队）

## 团队构成

| 角色 | 名字 | 职责 |
|------|------|------|
| 首席咨询官 | 齐谋远 | 编排调度、门禁把控、成果集成与审定 |
| 前期策划师 | 章启程 | 项目建议书、投资机会研究、建设内容与规模论证 |
| 市场研究员 | 苏晴雨 | 市场调研、需求与价格预测、竞争分析 |

| 政策报批专家 | 陆路通 | 政策符合性、审批路径、选址与报批报建 |

| 财务经济评价师 | 魏划算 | 财务评价、国民经济评价、融资与不确定性分析 |

## 功能

- **项目建议书 / 立项申请**：项目背景、建设必要性、建设内容与规模、投资初估
- **可行性研究报告**：主报告编制，含技术方案、方案比选、投资估算、财务与经济评价
- **专项评估报告**：环评、能评、稳评、水保、地灾等专项的判定、导则与初判
- **报批报建方案**：政策符合性、审批路径、选址用地、报批报建路径设计

### 工作流（SOP）

```
Phase 0 需求澄清 → Phase 1 并行调研(策划/市场/政策) → 用户确认(唯一交互点)
→ Phase 1.5 咨询大纲 → Phase 2 技术经济方案(可研/造价/财务) → Phase 3 专项评估
→ Phase 4 报告集成 + 三级校审 + 交付
```

### 核心质量机制

- **P0 绝对规则**：禁编造数据与政策依据 · 禁无依据结论 · 禁违反编制规范 · 数据必须勾稽一致
- **三级校审**：校核（编制人）→ 审核（评审总工）→ 审定（首席咨询官）
- **依据-数据-结论证据链**：每个数据可溯源、每条政策有文号、每个结论有推导
- **数据一致性 12 项勾稽**：分项=合计、投资口径=财务口径、规模三处一致

## 使用示例

- 我要建一个年产10万吨的新材料工厂，帮我做项目前期咨询
- 帮我编写一份产业园区项目的可行性研究报告
- 这个项目需要办哪些前期审批？帮我梳理报批报建路径

## 知识库

内置 `references/` 分层知识库（12 篇）：4 篇标准与校审规范 + 6 篇专业方法 + 2 篇报告模板。主理人调度成员时按映射表指定必读文件。

## 安装

将专家包目录放到专家目录下：

```
~/.workbuddy/plugins/marketplaces/my-experts/plugins/eng-preconsult-expert-team/
```

然后运行注册命令使其可见：

```bash
python3 <expert-manager>/scripts/register_expert.py <expert-dir>
```

## 打包分享

```bash
python3 <expert-manager>/scripts/package_expert.py <expert-dir>
```
