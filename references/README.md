# 知识库索引（references/）

> 工程前期咨询专家团的内置分层知识库。各成员在对应 Phase 开始前**必须**读取指定文件。

## standards/ — 标准与校审规范

| 文件 | 用途 | 主要使用者 |
|------|------|-----------|
| `standards/report-standards.md` | 报告编制规范、章节架构、深度要求、不合格项清单 | 策划师、可研工程师、评审总工 |
| `standards/policy-compliance.md` | 政策符合性分析维度与方法 | 政策报批专家、策划师 |
| `standards/data-consistency.md` | 12 项数据勾稽核对规则 | 全体编制人、评审总工 |
| `standards/three-level-review.md` | 三级校审制度、复核清单、缺陷分级 | 评审总工、主理人 |

## methods/ — 专业方法

| 文件 | 用途 | 主要使用者 |
|------|------|-----------|
| `methods/market-research.md` | 市场调研、需求/价格预测方法、数据来源规范 | 市场研究员 |
| `methods/approval-path.md` | 审批制/核准制/备案制判断、报批路径设计 | 政策报批专家 |
| `methods/option-comparison.md` | 方案比选维度与方法 | 可研工程师、造价/财务 |
| `methods/investment-estimation.md` | 投资估算方法、投资构成、筹措方案 | 造价估算师 |
| `methods/financial-evaluation.md` | 财务评价指标、报表、不确定性分析 | 财务经济评价师 |
| `methods/special-assessment.md` | 专项评估判定与技术导则 | 专项评估工程师 |

## templates/ — 报告模板

| 文件 | 用途 | 主要使用者 |
|------|------|-----------|
| `templates/project-proposal.md` | 项目建议书章节模板 | 前期策划师 |
| `templates/feasibility-report.md` | 可行性研究报告章节模板 | 可研工程师 |
