# 数据一致性标准（勾稽核对规则）

> 供全体编制人自校、评审总工复核使用。数据打架是前期咨询成果最致命的硬伤，触碰即 P0。

---

## 1. 必检勾稽关系（Checklist）

| 编号 | 勾稽关系 | 判定标准 | 责任方 |
|------|----------|----------|--------|
| DC-01 | 投资构成加和 | 工程费用+其他费用+预备费 = 建设投资 | 造价估算师 |
| DC-02 | 总投资构成 | 建设投资+建设期利息+流动资金 = 总投资 | 造价估算师 |
| DC-03 | 投资口径一致 | 投资估算总额 = 财务评价使用的投资额 | 造价+财务 |
| DC-04 | 资金筹措平衡 | 资金来源合计 = 资金运用合计 | 造价估算师 |
| DC-05 | 建设规模一致 | 产品方案规模 = 市场分析规模 = 投资估算规模 = 财务产量口径 | 全专业 |
| DC-06 | 价格口径一致 | 市场预测价格 = 财务收入单价 | 市场+财务 |
| DC-07 | 财务报表平衡 | 资产 = 负债 + 所有者权益 | 财务经济评价师 |
| DC-08 | 现金流平衡 | 现金流入 - 现金流出 = 净现金流量 | 财务经济评价师 |
| DC-09 | 建设期/计算期一致 | 各表建设期、运营期、计算期一致 | 财务经济评价师 |
| DC-10 | 财务生存能力 | 累计盈余资金各年 ≥ 0（或说明缺口及弥补） | 财务经济评价师 |
| DC-11 | 收入成本口径 | 营业收入、总成本费用口径与产量、单价一致 | 财务经济评价师 |
| DC-12 | 专项数据一致 | 环评/能评涉及的规模、工艺数据与可研一致 | 专项评估+可研 |

---

## 2. 复核方法

1. **纵向**：同一数据在不同章节出现时，逐一比对数值是否一致
2. **横向**：分项之和是否等于合计
3. **跨专业**：不同成员产出的接口数据（规模/投资/价格）是否吻合
4. **全表验算**：财务报表逐行验算平衡

---

## 3. 不一致的处理

- 发现不一致 → 列明"数据A（出处）/ 数据B（出处）"，指出应以哪个为基准
- 不自行篡改他人成果 → 通过主理人协调统一
- 所有口径以**咨询工作大纲**锁定的数据口径为准

---

## 4. 常见打架点（重点盯防）

- 建设规模在"产品方案""投资估算""财务产量"三处不一致
- 投资估算总额与财务评价投资额不一致（两套数）
- 分项投资之和 ≠ 合计（漏项/重复计列）
- 建设期/计算期在不同报表中不一致
- 单价在收入表与成本表中口径不同
