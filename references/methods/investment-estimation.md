# 投资估算方法与口径规范

> 供造价估算师使用，供财务经济评价师衔接。

---

## 1. 投资构成

```
总投资 = 建设投资 + 建设期利息 + 流动资金
建设投资 = 工程费用 + 工程建设其他费用 + 预备费
工程费用 = 建筑工程费 + 设备购置费 + 安装工程费
预备费 = 基本预备费 + 涨价预备费
```

---

## 2. 估算方法选择

| 方法 | 适用阶段/条件 | 公式/说明 |
|------|---------------|-----------|
| 单位生产能力估算法 | 机会研究 | 投资=拟建规模×单位能力投资×价差系数 |
| 生产能力指数法 | 机会研究/建议书 | I2=I1×(Q2/Q1)^n×CF（n≈0.6~0.8） |
| 比例估算法 | 建议书 | 以设备费为基数×系数 |
| 指标估算法 | 可研 | 按分项工程/单位指标估算 |
| 概算指标法 | 可研/概算 | 按概算指标×工程量 |

**要求**：必须说明所选方法、指标来源与基准期。

---

## 3. 精度与基准

| 阶段 | 精度 | 基准 |
|------|------|------|
| 机会研究 | ±30% | 说明价格水平年 |
| 项目建议书 | ±30% | — |
| 可行性研究 | ±10%~±20% | — |

估算表须声明"本估算基于XXXX年价格水平，精度约±X%"。

---

## 6. 纪律

- **分项之和 = 合计**（必检）
- **投资估算口径 = 财务评价投资口径**（必检）
- 不虚高不压低，指标贴合行业实际
- 所有指标注明来源；无来源的标注"测算指标"
