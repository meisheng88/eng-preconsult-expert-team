# 财务评价与国民经济评价方法

> 供财务经济评价师使用。依据《建设项目经济评价方法与参数》（第三版）通用框架。
> ⚠️ 具体参数取值须核实现行版本；基准收益率取值须说明依据。

---

## 1. 财务评价指标体系

| 指标 | 含义 | 判据 |
|------|------|------|
| 财务内部收益率 FIRR | 项目自身收益率 | ≥ 基准收益率 ic 则可行 |
| 财务净现值 FNPV | 按 ic 折现的净现值 | ≥ 0 则可行 |
| 投资回收期 Pt | 静态/动态回收期 | ≤ 行业基准/期望值 |
| 总投资收益率 ROI | 年均息税前利润/总投资 | 与行业对比 |
| 资本金净利润率 ROE | 年均净利润/资本金 | 与行业对比 |

---

## 2. 计算期与参数

- **建设期**：与实施进度一致
- **运营期**：按行业与设备寿命确定
- **计算期 = 建设期 + 运营期**
- **基准收益率 ic**：行业基准或企业要求，须说明取值依据
- **达产率**：投产期逐年达产安排

---

## 3. 主要报表

1. 营业收入、税金及附加和增值税估算表
2. 总成本费用估算表（含经营成本）
3. 利润与利润分配表
4. 项目投资现金流量表
5. 项目资本金现金流量表
6. 财务计划现金流量表
7. 借款还本付息计划表

---

## 4. 成本费用构成

```
总成本费用 = 外购原材料+外购燃料动力+工资及福利+修理费+折旧费+摊销费+财务费用+其他费用
经营成本 = 总成本费用 - 折旧费 - 摊销费 - 利息支出
```

---

## 5. 不确定性分析

### 5.1 盈亏平衡分析
BEP(生产能力利用率) = 年固定成本 / (年营业收入 - 年可变成本 - 年税金及附加) × 100%

### 5.2 敏感性分析
对关键变量（投资、价格、成本、产量）做 ±10% 变动，计算对 FIRR/FNPV 的影响：

| 变量 | 变动 | FIRR | FNPV | 敏感度系数 |
|------|------|------|------|-----------|
| 建设投资 | +10% | | | |
| 产品价格 | -10% | | | |
| 经营成本 | +10% | | | |

识别**最敏感变量**与**临界点**。

---

## 6. 财务生存能力分析

- 累计盈余资金 ≥ 0 → 可持续
- 出现资金缺口 → 说明缺口年份、金额、弥补方式

---

## 7. 国民经济评价（按需）

- 效益费用范围：直接+间接、内部+外部
- 影子价格（市场失真时）
- 社会折现率（现行取值须核实）
- 经济内部收益率 EIRR、经济净现值 ENPV

---

## 8. 纪律

- **投资口径 = 投资估算**；**收入口径 = 市场预测**
- 报表必须勾稽平衡
- 指标不达标如实报告，禁止调参凑指标
- 结论明确：财务可行 / 需调整 / 不可行 + 依据
