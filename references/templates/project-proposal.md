# 项目建议书模板

> 供前期策划师使用。章节结构可按行业规定调整，但**章节不可缺**。

---

```
# {项目名称}项目建议书

编制单位：{单位}
编制日期：{YYYY年MM月}

## 第一章 总论
1.1 项目概况（名称、单位、地点、建设内容与规模、投资、资金来源、建设期）
1.2 编制依据（政策、规划、标准——文号需核实）
1.3 研究范围与目的
1.4 主要结论（必要性/规模/投资/效益的初步结论）

## 第二章 项目建设背景与必要性
2.1 项目背景（政策背景、行业背景、区域背景）
2.2 建设必要性
   - 政策要求（依据 + 文号）
   - 市场需求（引用市场研究结论）
   - 区域发展需要
   - 企业战略需要

## 第三章 建设条件
3.1 建设地点与场址条件
3.2 资源/原材料/配套条件
3.3 公用工程条件（水、电、汽、路）
3.4 建设条件综合评价

## 第四章 建设内容与建设规模
4.1 建设内容（项目构成）
4.2 建设规模及确定依据（与市场容量、政策容量对齐）
4.3 产品/服务方案

## 第五章 技术方案与建设方案（初步）
5.1 技术路线（初步）
5.2 主要建设方案（初步）
（详细方案由可行性研究阶段完成）

## 第六章 投资估算与资金筹措（初估）
6.1 投资估算（初估，精度声明）
6.2 资金筹措方案（初步）

## 第七章 效益分析（初步）
7.1 经济效益（初步）
7.2 社会效益
7.3 生态/环境影响（初步）

## 第八章 结论与建议
8.1 结论（建议继续推进 / 谨慎 / 暂缓）
8.2 建议（下一步工作建议）
```

---

## 编制纪律

- 每个关键判断附依据（政策文号/数据来源/推导）
- 无来源数据标注"测算假设 + 口径"
- 投资估算精度声明（项目建议书阶段约±30%）
- 规模须有依据，不得拍脑袋
